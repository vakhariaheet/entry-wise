# Paste directly into Cursor Composer, Claude Code, v0, Bolt, or ChatGPT:

Integrate EntryWise (v0.2.0) into this project as the headless form backend.

### Target Endpoint:

- URL: POST https://entrywise.webbound.in/f/YOUR_SITE_API_KEY

- Headers: Content-Type: application/json (or multipart/form-data for file uploads)

### Implementation Rules:

1. Honeypot Bot Trap: Add <input name="_gotcha" style="display:none" tabIndex="-1" autoComplete="off" />

2. Cloudflare Turnstile: If using bot protection, include <input type="hidden" name="cf-turnstile-response" />

3. Status Handling: Expect HTTP 201 Created on success. On failure, parse RFC 7807 problem details response JSON.

// app/actions/submitForm.ts
'use server';

export async function submitContactForm(prevState: any, formData: FormData) {
  const apiKey = process.env.ENTRYWISE_API_KEY!;
  
  const response = await fetch(`https://entrywise.webbound.in/f/${apiKey}`, {
    method: 'POST',
    body: formData,
  });

  if (!response.ok) {
    const error = await response.json();
    return { success: false, message: error.title || 'Submission failed' };
  }

  const data = await response.json();
  return { success: true, submissionId: data.submission_id };
}
import { useState } from 'react';

export function ContactForm() {
  const [isSubmitting, setIsSubmitting] = useState(false);
  const [submitted, setSubmitted] = useState(false);

  async function handleSubmit(e: React.FormEvent<HTMLFormElement>) {
    e.preventDefault();
    setIsSubmitting(true);

    const payload = Object.fromEntries(new FormData(e.currentTarget));
    await fetch('https://entrywise.webbound.in/f/YOUR_SITE_API_KEY', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify(payload),
    });

    setIsSubmitting(false);
    setSubmitted(true);
  }

  return (
    <form onSubmit={handleSubmit}>
      <input name="_gotcha" style={{ display: 'none' }} tabIndex={-1} />
      <input name="email" type="email" required />
      <button disabled={isSubmitting}>{isSubmitting ? 'Sending...' : 'Submit'}</button>
    </form>
  );
}

Questions & Answers

Frequently Asked Questions

Everything you need to know about setting up EntryWise for personal projects or client sites.

Do I need a backend server or database?

No! EntryWise is completely headless and serverless. You only need to point your form's <form action="..."> or frontend fetch() to your unique endpoint URL. All submissions are stored in Cloudflare D1 SQLite automatically.

How does spam protection work without annoying CAPTCHAs?

EntryWise uses Cloudflare Turnstile for invisible cryptographic verification, an invisible honeypot field (_gotcha), automatic disposable email blocking, and customizable keyword blacklists. Legitimate users never see a puzzle.

What happens when I add new fields to my form?

EntryWise handles arbitrary dynamic fields seamlessly! If you connect Google Sheets, our Apps Script integration automatically detects new fields and appends them as new header columns in Row 1 without breaking existing rows.

Can I test my form before going live?

Yes! In the dashboard, you can trigger a 1-click Pipeline Smoke Test that tests edge commit, queue fanout, email alerts, and Google Sheets sync with realistic mock data. When you're ready, click "Clear Test Rows" to purge test records with zero impact on production data.

Is there a free tier for hobbyists and students?

Yes! You can start completely free. No credit card is required. You get unlimited forms, full access to connectors (Google Sheets, Discord, Slack, multi-webhooks), Turnstile bot protection, and CSV export.
